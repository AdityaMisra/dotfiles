dotfiles guide

What this setup gives you, how to use each part, which file controls it, and how everything connects. Links open the file in this repo. Paths starting with ~ are in your home folder: open them with zed <path>.

⌨️ Find any command

Ctrl-R searches everything you've ever run, across tabs.

⚡ Type less

Grey suggestions, fuzzy Tab, z to jump to folders.

🎨 15 themes

theme switches colours; the prompt and diffs follow.

🤖 Claude-friendly

Tab titles per repo, notifications, Cmd-click to open files in Zed.

🔒 Safe to publish

Commits are checked for secrets and personal details.

🖥️ One-command setup

./bootstrap.sh rebuilds the whole setup on a new Mac.

7. On a new laptop

git clone https://github.com/AdityaMisra/dotfiles.git ~/.dotfiles
cd ~/.dotfiles
./bootstrap.sh --dry-run   # preview
./bootstrap.sh             # install + link + configure
  1. If git asks to install the Command Line Tools, accept, then clone again.
  2. Bootstrap asks for your git name and email once, and Homebrew may ask for your password.
  3. Quit and reopen iTerm2 (⌘Q).
  4. Put your employer's setup in ~/.workrc and machine extras in ~/.zshrc.local.
  5. Run theme to pick colours.
